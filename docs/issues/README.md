## 提交前的检查清单

提给上游之前，对每份文档确认：

- [ ] 数据是可复现的，且写明了样本量与口径（例如 TTFT 是冷启动还是缓存命中）
- [ ] 不把"相关"写成"因果"；测量支持不到的说法要么删掉，要么显式标注不确定
- [ ] 区分**确定性事实**（结构调整、序列化次数）与**采样结论**（延迟、token 量）
- [ ] 引用上游代码时给出精确文件与行号
- [ ] 复现步骤不依赖本项目的私有代码
